# V1.5 当前输入、输出与证据边界

核对日期：2026-09-23。按依赖顺序重跑六个 V1.5 runner，并运行 V1.0 回归，全部正常退出。

当前已跑通固定 synthetic VCO 家族内的二维规格映射：SystemSpec → PN anchor × k1 联合评估 → 系统边界 → frozen-context BlockTB → PN margin → 条件规格 → PN–measured Kvco 联合规格 → 候选独立 replay。

这里的“正式二维 BlockSpec”指版本化的行为级实验规格。不能将脚本中的 formal 状态理解为连续域已获数学证明、任意 VCO 均适用或整个 V1.5 已完成。

## 输入

主配置：[vco_multidim_01.json](../v1/cases/vco_multidim_01.json)。

| 输入 | 当前值/含义 |
|---|---|
| SystemSpec | 5 GHz，频率容差 ±100 kHz，jitter ≤80 fs，lock time ≤34 µs，power ≤8 mW |
| 候选变量 | PN anchor：−124…−112 dBc/Hz，步长 1 dB；k1：0.55…1.40 GHz/V，步长 0.05 GHz/V |
| 设计空间 | 13 × 18 = 234 点，确定性顺序 |
| 行为模型 | 当前 synthetic VCO/PLL；其他模型参数保持固定 |
| 冻结测量条件 | 1.8 V、25°C、Vctrl 0.1…1.1 V、11 个 BlockTB 电压点 |
| 分配策略 | PN 固定 1.5 dB margin；联合规格采用每端收缩 50 MHz/V 的 Kvco guard band |

PN anchor、k1 是产生候选的输入旋钮；正式输出用测得的 worst PN、kvco_max 表达。当前上层脚本还固定了候选数量和位置，不能保证只换 case 就自动完成任意二维问题。

## 现在交付的规格

令 K 为冻结条件下 BlockTB 测得的最大 Kvco，P 为相同测量条件下最差 PN@1MHz：

```text
1.54 ≤ K ≤ 1.84 GHz/V
P ≤ PN_spec(K)
并满足频率覆盖、正 Kvco、功耗、context 和模型适用域条件
```

| K（GHz/V） | PN_spec（dBc/Hz） |
|---|---|
| 1.54 | −116.185715 |
| 1.59 | −115.981532 |
| 1.64 | −115.782430 |
| 1.69 | −115.588334 |
| 1.74 | −115.399156 |
| 1.79 | −115.214802 |
| 1.84 | −115.035168 |

例如 K=1.64 GHz/V 时要求 worst PN ≤−115.782430 dBc/Hz。这是一个联合接受区域，允许在区域内选择不同 PN、Kvco 组合，不会自动输出唯一最优组合。

50 MHz/V 是显式选择的、以网格为依据的保守收缩策略，不是仿真推导出的物理不确定性界限。1.49…1.89 是原有关系的观测支持域，也不等于精确 lock-time 可行边界。

依次执行，每一步成功后再执行下一步：


主要交付：

- `results/v1_5_vco_multidim_01/`：234 点记录、系统边界、边界 BlockTB、9 条条件分配、候选验证、Graph audit。
- `results/v1_5_continuity_v1_5/`：single-crossing、可行区间、off-grid 真值分配、插值误差。
- `results/v1_5_kvco_mapping_v1_5/`：measured Kvco 轴与 PN 边界的对应。
- `results/v1_5_joint_boundary_validation_v1_5/`：8 个 canonical 之外的中点、16 个边界邻近候选。这些 k1 中点复用了连续性实验的位置，不是另一组全新 k1 holdout。
- `results/v1_5_formal_joint_blockspec_v1_5/formal_2d_blockspec.json`：联合规则、7 个 PN–Kvco 节点、margin 和来源记录。

产物默认被 Git 忽略。最终 runner 消费之前生成的文件；目前不是统一入口从零自动调度全部步骤。

## 与 V1.0 的对应

V1.0 输出固定条件下的一个 measured PN 上限。V1.5 对二维候选空间提取边界，输出 measured Kvco 窗口与随 Kvco 改变的 PN 上限。二者都经过系统边界、BlockTB、margin、候选验证和 SystemTB replay。

本次 V1.0 回归：PN anchor boundary −116.358121 dBc/Hz，边界 worst measured PN −113.511151 dBc/Hz，最终 SystemTB PASS。
