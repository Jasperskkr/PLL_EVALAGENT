# Stage 4 — M2 Independent UGF / Phase Margin Measurement

## 一、角色与研究目标

你是资深 PLL 系统建模专家、混合信号行为仿真专家和科学计算工程师。

当前项目已完成 Stage 3A.1 主线整合，具备：

* 固定 Integer-N Charge-Pump PLL 拓扑。
* Behavioral Block Space Model v1，包含六个可分配参数。
* M1 线性频域模型，可预测 BW、UGF、PM 和 VCO 调谐点。
* Physics-guided Allocation 及 LLM Agent 工具编排。
* M2 事件级 System TB，已支持独立 BW 测量与捕获行为分析。
* 统一 Pipeline 和结构化验证反馈。

目前最大的验证缺口是：

**M1 能够计算 UGF 和 PM，但 M2 尚不能通过独立、可靠的行为级测量对它们进行认证。**

本阶段唯一核心目标：

**研究并尽可能实现 M2 事件级 PLL 中的独立 UGF/PM 测量，建立 M1 Prediction ↔ M2 Measurement 的定量对照。**

不要求新增 Block 参数，不要求改进 Agent 搜索算法，不考虑晶体管级实现。

## 三、Task A — 先研究 UGF/PM 的行为测量方法

这是本阶段最重要的技术任务。

首先审查现有：

* M1 Open-loop / Closed-loop Transfer Function。
* M2 PFD、CP、LF、VCO、Divider 事件仿真模型。
* M2 参考相位正弦注入与 BW 测量实现。
* Measurement Protocol 1.1。
* 现有 BW/UGF/PM 定义、相位符号与反馈归一化方式。

明确当前 PLL 模型属于含有参考时钟采样和 CP 开关行为的周期性系统，不能未经分析就将其完全视为连续时间 LTI 系统。

重点研究两种测量路径。

### A1. 直接环路注入 / Return Ratio Measurement

优先研究能否在 PLL 锁定状态下，选择合理的相位反馈注入位置，测量有效的开环返回比。

必须说明：

1. 注入点位于 PLL 的哪个功能模块之间。
2. 如何保持原有 DC 锁定工作点与平均控制电压。
3. 如何避免打开环路后因积分器漂移而破坏测量。
4. 注入信号如何影响 PFD/CP 的实际事件。
5. 返回信号如何被独立观测。
6. 如何处理负反馈符号、Divider N 和相位单位。
7. 如何判断测得的是正确的返回比，而非其他闭环传递函数。
8. 采样效应、参考周期纹波与谐波耦合是否影响标量返回比定义。

优先采用可解释、能够保持原模型事件语义的注入方式。

不得仅为了得到与 M1 接近的结果而直接构造 M1 的线性化反馈路径。

### A2. 闭环辨识辅助方法

可以研究由闭环参考相位响应推导有效环路增益的方法，例如在满足相应假设时使用：

L = T / (1 − T)

但必须明确这种关系成立的前提，并分析当前 PFD/CP 事件模型是否满足对应的标量线性化条件。

该方法初期只能作为诊断或交叉检查，不能未经独立论证就作为 M2 PM 正式认证依据。

### A3. 方法选择

比较两种方法的：

* 物理意义。
* 注入点有效性。
* 数值稳定性。
* 实现复杂度。
* 可测频率范围。
* 对 M1 公式的独立程度。
* 潜在的采样和谐波误差。

选择最适合当前模型的方案，并记录选择依据。

如果直接测量不可行，必须明确技术障碍及最小替代方案，不允许生成伪造的 PM 数值。

## 四、Task B — 先完成一个工作点的测量原型

先只使用现有 Nominal BlockSpec：

* fref = 10 MHz。
* N = 8。
* Icp = 100 µA。
* Rz = 3820 Ω。
* C1 = 100 pF。
* C2 = 1 nF。
* f0 = 72 MHz。
* Kvco = 20 MHz/V。

当前 M1 参考预测约为：

* UGF = 138.176 kHz。
* PM = 56.443°。
* BW = 222.379 kHz。

这些数字只能用于事后对照，不得作为 M2 测量结果或用于强制拟合频率响应。

### B1. 构建小信号实验

在 M2 锁定工作点附近施加小信号注入。

要求：

* 采用独立预设的频率扫描范围。
* 保留输入及返回信号的复数幅值和相位。
* 明确线性化工作点。
* 检查 PFD/CP 开关与控制电压状态。
* 检查参考/反馈边沿定义。
* 检查信号谐波和非线性失真。
* 检查实际限幅和锁定状态。

### B2. 提取频率响应

从实际仿真波形中提取复数返回比：

L_M2(jω)

在测量方法被证明有效的前提下，计算：

UGF：满足 |L_M2(jω)| = 1 的单位增益交越频率。

PM：对应有效单位增益交越处的相位裕量。

PM = 180° + arg[L_M2(jω_UGF)]

必须正确处理：

* 相位展开。
* 反馈符号。
* 多个交越频率。
* 高频噪声及谐波。
* 频率分辨率。
* 采样频率与混叠。
* 不存在有效单位增益交越的情况。

不得使用闭环 −3 dB BW 代替 UGF。

### B3. 数值可信度检查

至少研究：

1. 注入幅度减半后的结果是否一致。
2. 时间步长减半后的结果是否收敛。
3. 测量窗口增加后的结果是否稳定。
4. 不同频率网格及交越细化策略是否一致。
5. 测量期间锁定点是否保持稳定。
6. 原有 BW 测量是否受到新增代码影响。

收敛门限应在正式测量之前声明，不能根据最终结果倒推设置。

只有得到可信的复数返回比及收敛证据，才能输出独立测量的 UGF/PM。

## 六、Task D — 建立预测与测量误差反馈

本阶段不开发新的 LLM Repair Algorithm。

只建立一套最小、可靠的指标对照机制。

对于每个候选保存：

* 完整 BlockSpec。
* M1 Prediction。
* M2 Measurement。
* M1/M2 Error。
* M2 Measurement Validity。
* 是否满足当前 SystemSpec。
* 可能的误差来源。
* 需要进一步检查的模型条件。

反馈至少区分：

**SPEC_VIOLATION**

测量可靠，但指标不满足 SystemSpec。

**MODEL_DISAGREEMENT**

测量可靠，但 M1/M2 存在明显预测偏差。

**MEASUREMENT_UNRELIABLE**

测量结果尚未收敛或存在严重失真。

**UNSUPPORTED_METRIC**

当前方法无法可靠测量该指标。

**OUT_OF_DOMAIN**

候选超出模型或协议的适用范围。

以上类别允许作为诊断标签组合存在；不要将测量不可靠直接等同于规格失败。

对于 MODEL_DISAGREEMENT，要求区分：

* 物理近似不足。
* 采样/开关行为影响。
* 测量定义不一致。
* 数值积分误差。
* 参数或单位语义错误。

本阶段不自动修改 M1 公式，不训练校准模型，不让 Agent 擅自改变 Block Space。

反馈结果需要能够被现有统一 Pipeline 读取，并保留指标级 PASS / FAIL / UNKNOWN 和证据来源。

## 七、Task E — 回归、验收与研究结论

### E1. 回归要求

执行现有主线全部可运行的回归测试，并新增对应的 UGF/PM 测量测试。

必须确认：

* 原 BW 预测和测量结果保持一致。
* 原 Capture / Lock 结果不被破坏。
* 新增注入接口不会改变无扰动事件模型。
* 现有 Allocation / LLM Agent 正式入口仍然可用。
* SystemSpec 和 Block Space 不被静默修改。
* UNKNOWN 状态不会被伪装为 PASS。

### E2. 科学验收要求

重点不是一定得到与 M1 很接近的 PM 数值，而是证明测量方法本身可靠。

至少完成：

1. 独立注入与观测方法的可执行实现或有证据的不可行性结论。
2. Nominal 工作点的测量和完整数值诊断。
3. 对测量方法的幅度、步长及窗口敏感度分析。
4. 对比 M1 与 M2 频率响应的复数幅值、相位及交越情况。
5. 不改变已有 BW 测量和历史参考结果。
6. 成功时扩展至其他两个工作点；失败时明确说明阻碍及最小修复建议。

允许研究结论为：

**UGF / PM M2 MEASUREMENT NOT YET VALIDATED**

这比通过未经验证的数学反算制造 PASS 更符合本项目的研究目标。
