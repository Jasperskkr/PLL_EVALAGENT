# 后续 Agent 边界及 B3 静态预分析

本阶段未实现或调用 LLM/BO/TuRBO。未来可把 `SearchController.next/observe` 替换为外层策略接口：输入冻结问题、原 M1 敏感度、历史候选/独立约束判决、实际预算；输出完整原合同候选、选择的物理区域/工具、修改理由或停止请求。可开放电容区域选择、变量激活、解析/SLSQP/局部搜索策略、候选优先级与继续/停止建议。

Runner 保留输入绑定、完整候选检查、原 M1/完整 M2 调用、预算上限、首次候选先落盘、缓存与最终判决。策略不能写入结果 PASS、跳过硬约束或越过总预算；未执行新 LLM 时必须明确回放/确定性来源。外层预算建议不得扩大已冻结上限。

本轮仍固定的规则包括初始解析求解、1%敏感度、SLSQP guard、词典序目标、Vreq/Kvco 轮询顺序、退化阈值、信赖半径与区域排序。可以用相同 Runner/证据合同做后续消融，不能把本轮确定性算法的结果计作 LLM 决策收益。

六参数空间不表达 CP mismatch/dead-zone、PFD reset delay 设计、VCO非线性/噪声/输入阻抗、器件相关性、工艺角、杂散/抖动、寄生与真实电路实现能力。多初态鲁棒捕获同样不是本轮单一初态证据可覆盖的目标。

B3 只读检查：原 `verification/simulator.py::simulate` 接受 `initial_control_V`；原生内核相位和PFD状态初始化固定。原 `capture_pair`/完整 verifier 按原协议固定0.15V和160µs。低层可传其他电压不等于正式多初态接口已经完成。将来应新增版本化初态合同、明确两LF电压/相位/PFD状态/窗口、逐初态成本、协议哈希/缓存键和稳健汇总判决；保持旧协议可复现。若开放独立LF电压及相位/逻辑状态，需要扩展内核请求而非悄悄复用旧状态。本阶段未改内核、未运行其他初态，不作全局捕获保证。
