## 每次反馈实际发生了什么

B1 C 首次同 B。Vreq−0.08V 保持原 Icp/Rz/C1/C2/Kvco，只重建 f0，将捕获从37µs改为33µs，包络分离，且BW/PM保持。Vreq+0.08V 则测得40µs，区间39–41µs穿过40µs上限，正确判 UNKNOWN；程序停止测量诊断并保留先前33µs可行候选。没有删去这次不确定结果，也没有继续搜索替它制造成功。

B2 C 首次同 B。负Vreq候选23µs；正Vreq会超过原 f0 范围，提前拒绝并保留原参数域。随后成对Kvco扰动、区域访问，均测23或24µs。所有区间重叠，最小归一化裕量仍由PM控制（2.247210°/70°=0.032103），故只能说次级排序的点估计改变，不能说可靠捕获提升或主目标改善。第5槽区域候选与此前解析点精确重复，记录缓存命中，仍消耗槽；A和B极微小浮点参数差异未做近似合并。第6槽后预算停止。

各候选完整六参数、M1 BW/PM/UGF/Vreq、M2 BW/控制电压/捕获、包络及逐项判决在 `summary_01/candidates.json/csv`、`study_01/runs/*/candidate_*`。原始冷捕获测量保留块内相位/频差/控制电压、rail/clamp/终端滑周等原协议诊断；未把现有诊断外推为额外规格。敏感度、优化元数据、拒绝理由和修改历史在逐方法 trace。

## 对研究问题的回答

1. **敏感度是否改善首次分配？** 本轮没有。B1的SLSQP首次捕获37µs劣于解析33µs；B2同为24µs、同一PM瓶颈。原SLSQP优化的是带局部guard的M1联合裕量，不包含可信解析捕获模型，二者不等价。SLSQP实际使用了敏感度，B2求解未找到更好合法区域而保留等效解析候选；不是把敏感度报告当优化效果。
2. **M2反馈是否改善？** B1相对其自身B首次点有明确局部改善，最终与A持平；B2只有包络重叠的1µs点估计变化，无可靠增益。全部首次已可行，所以本轮未展示从联合失败恢复可行性的正式收益。
3. **是否优于旧单指标Repair？** 不能据此下结论。旧Repair不是本轮另一个同起点同预算正式arm。Stage6A历史边界FAIL→BW缩放PASS仅作保留参考；新BW反馈分支覆盖了合成测试和历史边界判决，但B1/B2正式实验没有BW FAIL，不能宣称正式验证了通用BW恢复。可证明的新能力是调谐/增益分摊行为搜索、完整重检与可追溯预算，而非普遍性能优势。
4. **何时Analytical足够？** 这两个声明目标均首次可行，且B1得到与C相同捕获、B2主裕量相同，成本最低。对本轮既定任务A已经足够。
5. **何时真正需要反馈？** 当要求改善SLSQP候选的行为捕获、或未来遇到M1无法解释的行为违例时有必要；B1表明只改f0可改变捕获而不改M1频域预测。本轮不证明反馈是获得B1/B2可行解的必要条件。
6. **六参数空间尚不能表达什么？** CP/PFD非理想、非线性VCO、噪声/抖动/杂散、器件相关性/工艺角/寄生、真实器件能力、多初态鲁棒性等。B2紧PM要求也限制可用电容区域，不是允许区域切换就一定存在另一种可行拓扑。
