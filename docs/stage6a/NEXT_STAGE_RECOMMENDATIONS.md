# 下一阶段研究建议（基于 Stage 6A 实验）

当前模型足以继续开展范围明确的**研究级**多指标分配：M1 BW/PM/严格内部调谐联合筛选，M2 独立 BW 和固定初态/窗口下的条件捕获测量。尚不足以声明完整 SystemSpec 通过，也不足以覆盖真实电路实现、所有启动初态、周期系统稳定性、噪声和功耗。

优先补充的最小能力是**条件捕获测量覆盖协议**，而不是再写一个分配 Agent。保持本轮定义，系统列出初始控制电压、两LF状态、初始相位、失谐与观测窗口，先验证重复性和数值收敛，再研究是否出现真实行为失败。当前0.15 V/160 µs仅一个条件；同M1动态候选的33/36/38 µs差异说明捕获不能由BW/PM替代，但这三例都满足预先40 µs上限，不能据此声称已证明捕获反馈优化的必要性或增量价值。不同电容的E0候选锁定更快也只是有限配对证据，不能外推“更低PM总是捕获更快”。

如果研究目标要求**独立测量PM联合分配**，则下一最小工作是补全周期/谐波返回比与稳定性定义及验证桥接。Stage4局部Series/Clamp PM不能直接用作严格周期PM PASS；亦不能把M1预测作为M2认证。严格1 µHz频率要求需要独立的精度/不确定度协议；本轮ppm捕获门限不能替代它。

已有 Analytical Solver 与 SLSQP 已足以解决当前大部分M1联合约束：乘积降维、离散电容枚举、形状/尺度反解和调谐求交。E1存在真实BW–PM–域竞争，也存在M1可行而M2越过BW边界的反例；现成确定性反馈修复可以处理该局部误差，无须引入完整BO/TuRBO。

本轮没有证明需要外层LLM区域规划和内层BO。当前没有高维未知非凸行为目标、多个失效区域和足量独立误差证据来支持额外系统成本。建议顺序：先扩展/冻结行为测量覆盖与可信度，积累少量跨区域失败与修复案例；随后比较确定性修复和预算受控的行为反馈搜索。如果届时出现现有求解器无法处理的、可重复且非平凡的行为约束竞争，再评估区域规划和BO。Jitter/Power在没有可信机制和指标协议前保持UNSUPPORTED，不进入联合成功统计。

Stage6A结束后停止；本文件仅为建议，不自动启动下一阶段，不合并master。
