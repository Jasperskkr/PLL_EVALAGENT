# 六参数联合可分配性：M2 前分析

权威前置扫描为 `experiments/stage6a/analysis_02`。analysis_01 是候选选择草案，保留未覆盖；第二轮在任何新 M2 前增加不同电容见证点、把边界点固定在 299.5 kHz。两轮不是独立统计样本，全部分析成本均保留。

原轴不变：Icp 50–200 µA，Rz 2–8 kΩ，C1={50,100,200} pF，C2={0.5,1,2} nF，f0 60–76 MHz，Kvco 10–40 MHz/V。四个连续轴与两离散轴不等于六个独立动态自由度。

固定电容时，连续小信号响应只依赖 Rz 与乘积 P=Icp·Kvco；Icp、Kvco 对 BW/UGF/PM 的局部列相同，f0 的动态列为零。Kvco/f0 决定 Vreq=(80 MHz−f0)/Kvco 和初始失谐；Icp 单独决定控制节点充电幅度。同 RC、同 P、同 Vreq 的理想模型经电压到频率变量变换基本等价，rail 和初始频率不同则会破坏该等价。不能保证相同 BW/PM 必然同捕获时间。

全部九个电容组合、5个Icp、7个Rz、5个Kvco、3个f0共4,725个确定性网格点，4,095个调谐合法，E0（BW150–300kHz/PM≥50°）有602个公式预测可行点。此数字是网格覆盖结果，不能当全域可行率。六个电容对的 PM 上界≥50°；三个被电容比上界排除。不同绝对电容改变所需 P/R 范围，同 C2/C1 仅保持 PM 上界，不保持 BW 尺度。详细乘积范围、离散组合与全部失败点见 CSV/summary。

E1 取 BW290–300kHz、PM≥70°：只有50pF/2nF电容对的理想 PM 上界72.2472°足够。粗网格可行数为0，但条件形状扫描找到53个非空区间，已有解析分配器也找到可行候选，因此“网格没找到”不能报告不可行。定义 q=1+C2/C1，x=ωu·Rz·C2，β=BW/UGF；复用既有数值根后 Rz=aR/BW，P=aP·BW²，将 BW区间与Rz/乘积/PM区间求交。578条条件记录中，E0有369条非空，E1有53条；不声称精确六维体积。

真实竞争：E1低PM边界分支 x≈3.83587，PM≈70.04347°，Rz下限导致BW≤203.845kHz，与290–300kHz目标冲突；峰值形状x≈6.40312和高分支x≈10.68831仍可行。高分支候选取BW299.5kHz、PM70.04369°，两个裕量都很小，适合检验M1/M2误差与判决边界。调谐本身在自由f0下不形成强竞争：每个原Kvco都有合法f0可选。没有人为引入第三项冲突。

这构成有意义的 BW–PM–声明域协调，但现空间较简单：电容枚举、形状与尺度反解、增益分摊和调谐求交已大幅降维。现有 Analytical/SLSQP 足以生成本轮候选，无证据表明必须引入外层 LLM 区域规划或 BO。

M1正式扫描评价24次的计时中位数约34.10ms；已有廉价代数根4,725点评价中位数约57.8µs，二者分别计数。M2尚未在本报告写入时运行，不预先宣称速度比或真实电路保真度。局部灵敏度、逐候选完整M1、求解器全部事件与复用SHA已落盘。

正式实验计划 `frozen_01/experiment_plan.json` 固定7个初始完整M2、最多1次已有确定性repair、1次重复capture pair、40µs条件锁定研究上限；判决加入原1µs块分辨率，不改变Protocol1.1。E0解析点同时作为E2中心对照和历史Baseline回归，避免重复完整仿真。所有首次完整候选在M2前已落盘。
