# Stage 6C — 实施与研究证据报告

日期：2026-11-10。执行目录为 `stage7-noise-nonideal/PLL_allocation`，分支为 `codex/stage7-noise-nonideal`；Stage7 名称仅保留工作区建立时的溯源身份。本报告按用户补充的完整 **Stage 6C** 要求评价成果。

## 结论与证据范围

本轮已把噪声预测、非理想行为与独立随机测量接入原正式 `python -m pll_allocation pipeline`。两个预声明环境各执行 A/B/C，共六组，首次与最终都满足本轮七项研究约束。C 利用完整 M2 的捕获反馈改变联合规格，在两个环境中把条件捕获时间分别从 33/32 µs 改善到 29 µs；全约束复验后最小归一化裕量从 0.15/0.175 提高到 0.204120164。

**这不是完整原 SystemSpec 认证，也没有证明加入 jitter 约束改善了选型。** 100 ps 上限在本轮场景中不活跃：独立比较显示原 noise-off SLSQP 与本轮 noise-hook B 的参数完全一致。六组首发均可行，故未证明首发可行率提升或失败修复增益。Jitter 置信区间重叠，不能声称 C 显著降低随机 jitter；严格周期 PM、全局稳定性及原微 Hz 频率精度继续 UNKNOWN。

## What：实际交付了什么

1. `physics_mapping/noise.py`：保留原连续 M1，新增 reference、VCO、等效 CP 电流及 Rz 支路热噪声的独立源传播、方差积分、贡献与冻结源谱条件下的敏感度。离散电容用候选枚举；没有引入 jitter∝1/Kvco 或 1/Icp。
2. `verification/stage6c_*`：从原内核受控生成可选扩展，使用原固定时间网格和步内边沿插值。加入锚定二次 VCO、真实 UP/DOWN 电流失配、compliance/leakage、reset 同时导通区间及电荷统计。关闭全部扩展直接调用原模拟器。
3. `verification/noise.py`、`noise_tracking.py`：独立种子/源流、dt 物理方差、VCO 积累相位噪声、CP 等效与门控噪声、Rz 正确支路热噪声、明确重构谱的参考噪声，以及锁定后 PSD/频带 jitter 测量。
4. 原 `pipeline`、原 Stage6B 约束评价和确定性 Pattern Search 的可选扩展：每项约束记录来源、单位、边界、模型/Profile/协议、数值或统计区间与证据路径。所有硬 FAIL/UNKNOWN 阻止联合可行。
5. 版本化配置、原始波形/PSD/每 seed 统计、真实 native 请求与成本、失败记录、首次候选和反馈轨迹。可复现包不包含预编译 DLL，必须独立重建并校验身份。

正式功能归属仍为 M1=`physics_mapping/`、Allocation=`allocation/`、M2=`verification/`。模型验证脚本仅负责机制实验；六组研究均由原 CLI 启动。冻结 `allocate.py` 未改；可选 SLSQP 噪声硬裕量通过检查原函数唯一锚点后生成，记录原函数及生成函数 SHA，不另维护第二套求解器。

## Why：这些改动要解决什么

旧 M1 能计算名义 BW/PM，旧 M2 能提供条件捕获与频响证据，但没有受验证的随机 jitter 测量。仅在优化器中附加一个经验 jitter 公式会把假设误当物理能力；用捕获轨迹 RMS 又会混合瞬态、确定性 ripple 和随机噪声。

本轮把三个层次分开：M1 给快速连续预测；固定网格行为 M2 独立演化脉冲与随机状态；Runner 在冻结条件、预算及证据合同下判决。源谱是研究环境参数，优化器不能免费改噪声系数。M1/M2 一致只支持本行为模型与小噪声条件，不能证明器件准确度。

## How：如何建立可信证据

### 噪声协议与统计

正式协议1.1：原确定性捕获门、200 µs warm-up、100 µs noise-on 建立、完整 4 ms 观察；5 个独立 seeds `[11,23,47,71,101]`；dt 为 0.4/0.2 ns；记录间隔 20 ns。Welch Hann 16384、50% overlap，Δf=3051.7578125 Hz，积分 10 kHz–1 MHz。相同非理想条件的 noise-off 基线用于分离确定性分量；没有任意删谱线。

原协议1.0把旧 1 µs/100 ppm 确定性门直接用于白频率噪声，VCO/all 得 UNKNOWN。独立 40000 块及解析方差确认正常随机频率波动会超此门后，先落盘依据、冻结新协议再新跑；原 UNKNOWN 不改判。1.1 保留原门作为诊断，使用无滑周/限幅/越轨、相位/控制范围及半观察窗平均频率判有限跟踪。具体依据和失败见 `NOISE_TRACKING_PROTOCOL_REVIEW.md`。

独立种子积分方差构成近似 Student-t 区间；Welch 重叠段不充当 Monte Carlo 样本。保留两个 dt 的区间并取包络，另检查方差随 dt 收敛。这不是严格统计覆盖或数值误差定理。区间上限低于硬 jitter 上限才 PASS，相交或统计证据不足为 UNKNOWN。

### 冻结 A/B/C 联合分配结果

冻结 `joint_frozen_01` 的 J0 理想与 J1 combined 环境：BW 200–250 kHz、名义 PM≥60°、内部调谐点、条件捕获≤40 µs、jitter≤100 ps、名义 Routh、有限扰动恢复。每方法最多 6 候选槽、96 M1、10000 cheap；每个新候选完整同精度 M2。A/B 按原定义首发后停，C 可用剩余槽反馈。缓存命中消耗候选槽但不冒称新 TB；所有方法输入/噪声谱/非理想/seed精度相同。

六组初始联合可行率与预算内最终可行率均为6/6，每方法仅2/2场景，不能外推一般成功率。C 改善的是这两个条件下的捕获裕量；未提高本批次可行率、未证明 jitter 优化或一般 Pareto 优势。原 SLSQP 与 noise-hook B 的参数 SHA 完全相同，jitter 裕量约0.36892，因此必须把“接口已实现”与“噪声约束改变选型尚无实验证据”分开。
