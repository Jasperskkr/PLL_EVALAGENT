# A1 可执行逆向关系

权威模型是 `physics_mapping/model.py`，17个输入及原 conventions 完整保留。定义 K=Icp·Kvco/N，CΣ=C1+C2，ωz=1/(RzC2)，q=1+C2/C1，ωp=qωz：

`Z=(1+sRzC2)/(sCΣ+s²RzC1C2)`；`L=KZ/s`；`T=L/(1+L)`。CP增益 Icp/(2π) A/rad 与 VCO 2πKvco rad/s/V 的2π相消。BW必须从归一化T的半功率交越求解，不能以UGF代替。

频率计划 F=Nfref固定，f0为零伏截距，Vreq=(F−f0)/Kvco，必须严格位于电压轨之间。给定产品P=IcpKvco，Kvco可选交集为 `[Kvco_lo,Kvco_hi] ∩ [P/Icp_hi,P/Icp_lo]`；再令 Icp=P/Kvco。选择Kvco与f0改变调谐位置，不改变固定产品下的环路。中心调谐要求f0=F−Kvco(Vmin+Vmax)/2；若f0超域则投影后重新检查调谐。

令 x=ωuRzC2，则 `PM=atan(x)−atan(x/q)`。其最大值 `asin((q−1)/(q+1))` 在 x=√q取得。PM≥φ 对应 `t x²−(q−1)x+tq≤0`，t=tanφ；判别式负值排除该电容对。小根用数值稳定形式 `2qt/(q−1+sqrt(D))`，大根=q/小根。50°至少需要C2/C1≥6.548632，九对中三对不满足；全域上界72.247210°。这只是必要条件，R、产品、调谐交集还需检查。

逆向自由变量选电容对、形状x、目标BW与产品分摊Kvco。定义 h=√[(1+(x/q)²)/(1+x²)]，y=(ωBW/ωu)²，则BW方程是

`(x/q)² y³ + (1−2h x²/q)y² − (2h+h²x²)y − h² = 0`。

该唯一正根以log尺度二分数值求解，β=√y。给定B，ωu=2πB/β，`Rz=x/(ωuC2)`，`K=CΣωu²h`。电容枚举、PM上界、R/K/f0反解属于解析关系；β以及廉价正向的两个幅度根属于数值求根，不包装为解析闭式解。廉价结果是同物理方程的预测，独立调用原M1签发M1判决。

固定电容时，Rz'=Rz/a且P'=a²P可使L'(s)=L(s/a)，因此BW/UGF均×a而PM不变。只改变Icp不会保持PM。当前正值理想模型的bc−ad=KRzC2²>0，低PM是规格失败，不是连续模型不稳定；以上推导不能证明事件捕获。

解析基线每对取x=√q、BW区间中心，合法产品内取Kvco交集中心，投影中心调谐，再按最小归一化裕量选完整候选。若这些有限形状未找到合法点只能NOT_FOUND。优化允许x离开峰值，以系统裕量和参数域裕量折中。归一化BW按半区间宽，PM按规格下限绝对值，连续参数按半范围，调谐按半电压范围；属于显式工程准则。固定频率等式仅硬检查，不进入maximin。
