## 提取而非搬迁

1. 原始任务按字节保存 PROJECT_CHARTER.md；AGENTS.md约束今后的每次工作。
2. 对必要文件逐字节复制到 `pll_allocation/_legacy/`；`legacy_manifest.json` 写原绝对路径和SHA。模型锚点和冻结输入放 `data/legacy/`。不迁移旧整仓，不执行旧工具的隐式路径探测。
3. 新 ProblemBuilder 适配原80MHz三指标和84MHz五轴声明域。旧 schemas.validate_request 的固定80MHz限制保留原件，新入口不调用它。
4. Python Behavioral Backend 把完整五Block规格转换为旧内核输入；新判决器只读实际测量。FastScreen 不跑隐藏的完整TB。
5. 验证：旧24组 MATLAB 记录对应数值测试；新接口、异常、超域、预算、首次保存、可复现和外部Backend测试。只把本轮实际执行计入报告。
6. 外部验证器协议先落盘并提供可注入实现；MATLAB实机Adapter后续按同合同接入，不用空接口宣称已连接。
7. 新产生的每组结果独立输出；原来任何失败或UNKNOWN都原地保留。

## 兼容与回滚

新目录与旧树没有导入/写入依赖，回滚只需停止使用本目录。提取文件有原哈希，测试核对；source_inventory_after 与 before 比较保护范围。本轮不迁移/删除原数据、不改变旧分支、不自动提交历史仓库。
