# V1.0 Baseline

This snapshot freezes the reproducible SystemSpec-to-VCO-Spec behavioral demo
before graph-schema evolution work begins.

## Scope

The baseline is a deterministic integer-N CPPLL model with a context-aware VCO.
It proves the following closed loop:

```text
SystemSpec
  -> deterministic SystemTB
  -> residual and finite-difference sensitivity
  -> required VCO PN boundary search
  -> candidate VCO
  -> context-aware VCO BlockTB
  -> realized-instance SystemTB validation
```

The formal V1 allocation dimension is `phase_noise_1mhz` versus integrated
jitter.  Kvco, Vctrl envelope, tuning and power are emitted as supporting
characterization and sensitivity evidence.

## Reproduce

From the repository root:

```powershell
python -m unittest discover -s tests -v
python run_v1_prove.py --case v1\cases\vco_mapping_01.json
```

The runner writes deterministic artifacts to
`results/v1_vco_mapping_01/`.  The full per-cycle traces are intentionally
ignored by Git because they are large and are regenerated by the command
above; summary, allocation, sensitivity, graph and provenance artifacts are
tracked.

## Acceptance evidence

- Test suite: 10 tests passed.
- Initial integrated jitter: approximately 83.367 fs (fails the 80 fs limit).
- Required PN boundary: approximately -116.358121 dBc/Hz.
- Recommended PN with margin: approximately -117.858121 dBc/Hz.
- Selected candidate: `candidate_low_noise`.
- Final integrated jitter: approximately 41.783 fs.
- Final lock time: approximately 36.520 us.
- Final output frequency: 5.000 GHz.
- Final SystemTB: PASS.
- Replay test: identical deterministic outputs.

## Boundary of the claim

This is a behavioral mapping proof, not transistor-level PLL signoff.  The
current jitter result contains the VCO phase-noise contribution only; CP,
divider and continuous-time loop-filter noise are not yet modeled as separate
signoff-quality sources.  The Python runner is canonical, with MATLAB used as
an equation-level cross-check.

The next graph-schema work must preserve this baseline and demonstrate that
the original tests, boundary, candidate, and final SystemTB result remain
unchanged.
